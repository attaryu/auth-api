# Auth API Service

Layanan API sederhana untuk autentikasi pengguna menggunakan Node.js dan Hapi.js. Project ini bagian dari latihan penerapan clean architecture dalam pengembangan aplikasi backend.

## Getting Started

1. Clone repository ini ke lokal mesin Anda.
2. Jalankan `pnpm install` untuk menginstal semua dependensi yang diperlukan. (Sesuaikan dengan package manager yang Anda gunakan)
3. Copy file `.env.example` di root direktori menjadi `.env` dan isi sesuai kebutuhan.
4. Jalankan `pnpm migrate up` untuk menjalankan migrasi database.
5. Jalankan `pnpm start` untuk memulai server.

## Upcomming Features

- Mendapatkan autentikasi atau proses login
- Memperbarui autentikasi atau refresh access token
- Menghapus autentikasi atau proses logout
